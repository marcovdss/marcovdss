# Hey, I'm Marco!

I'm a developer from Brazil. I mostly work with web development and information security, but I have a habit of getting sidetracked by whatever catches my interest.

I like figuring out how things work, taking them apart, and occasionally spending an entire weekend solving a problem that probably didn't need solving.

A good chunk of my free time goes into game modding, reverse engineering, and building tools for things I enjoy. Sometimes a small idea turns into a much bigger project than I originally planned.

### A bit about what I do

- **Full-stack development** — Mostly React, Node.js, and TypeScript. From building interfaces to figuring out why something works locally but breaks everywhere else.
- **Information security** — Secure coding, security research, vulnerability analysis, and understanding what happens beneath the surface.
- **Reverse engineering** — Digging through software internals, analyzing binaries, debugging, and figuring out how to make things behave differently.
- **Game modding** — Writing code, changing mechanics, building systems, and trying not to break three other things in the process.
- **Tools & automation** — Python scripts, development tools, and anything that saves me from doing the same tedious task twice.
